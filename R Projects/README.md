# Statistical Analysis & Simulation in R

## 📌 Overview
A collection of R scripts focused on statistical analysis, simulation, and inference. These projects demonstrate core statistical concepts using real data, Monte Carlo methods, and resampling techniques.

## 🛠️ Key Features
- Custom statistical functions with input validation  
- Monte Carlo simulation and randomness testing  
- Bootstrap methods for inference  
- Time series modeling and residual diagnostics  
- Data visualization using base R graphics  

## 💡 Concepts Used
- Exploratory data analysis  
- Monte Carlo simulation  
- Random number generation and testing  
- Bootstrap inference  
- Time series modeling  
- Statistical hypothesis testing  

## ▶️ How to Run
1. Open the `.R` files in RStudio
2. Run the scripts sequentially
