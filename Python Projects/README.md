# Statistical Modelling & Regression Analysis in Python

## 📌 Overview
A collection of Python-based statistical modelling projects focused on regression analysis, classification, model selection, and regularization. These projects demonstrate core statistical and machine learning concepts using optimization methods and resampling techniques.

## 🛠️ Key Features
- Custom implementation of linear and logistic regression  
- Gradient-based optimization for model fitting  
- Bootstrap methods for statistical inference  
- K-fold cross-validation for model evaluation  
- Ridge regression (L2 regularization)  

## 💡 Concepts Used
- Multiple linear regression  
- Logistic regression for binary classification  
- Maximum likelihood estimation  
- Cross-validation (model evaluation)  
- Feature selection and model comparison  
- Regularization and bias-variance tradeoff  

## ▶️ How to Run
1. Open the `.ipynb` files in Jupyter Notebook or VS Code  
2. Run the notebooks sequentially from top to bottom
